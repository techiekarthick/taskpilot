# **App Name**: SwiftTask

## Core Features:

- Task Creation: Add new tasks to the to-do list with a title and optional details.
- Task Display: Display tasks in a scrollable list.
- Task Completion: Mark tasks as complete, which grays them out and moves them to the bottom of the list.
- AI Task Suggestions: Use generative AI to offer suggested tasks or subtasks, based on the user's current tasks, using a large language model as a tool.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) for a calm and friendly feel, reminiscent of iPhone's native apps.
- Background color: Light gray (#F5F5F5), very slightly tinged with the hue of the primary, for a clean backdrop.
- Accent color: Light periwinkle (#CCCCFF), slightly less saturated than the primary, used sparingly for highlighting interactive elements.
- Clean and modern sans-serif font for readability.
- Simple, outline-style icons for task management actions.
- Use card-based layout with rounded corners for a modern, app-like feel.
- Smooth transitions and subtle animations on task completion and list updates.
